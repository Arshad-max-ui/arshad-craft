# Arshad Craft — GitHub Pages Website

This version uses the 24 real product photos supplied in `products/` and is ready for GitHub Pages.

## Upload
1. Open your `arshad-craft` repository.
2. Click **Add file → Upload files**.
3. Upload **everything inside this folder** (including the `products` folder).
4. Commit changes to `main`.
5. GitHub Pages will publish the update automatically.
