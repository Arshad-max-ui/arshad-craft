# Arshad Craft — Free GitHub Pages Website

## Files
- `index.html` — website structure
- `style.css` — design
- `script.js` — products, cart and WhatsApp ordering

## Before publishing
Open `script.js` and change:

`const WHATSAPP_NUMBER = "91XXXXXXXXXX";`

Replace it with your real WhatsApp number, including country code, without `+` or spaces.

You can also edit the `products` array to change product names, prices, descriptions and categories.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new **Public** repository, e.g. `arshad-craft`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open repository **Settings → Pages**.
5. Under Build and deployment choose **Deploy from a branch**.
6. Select **main** branch and `/ (root)`.
7. Save.
8. GitHub will provide your free `github.io` website URL.

No hosting payment or custom domain is required to start.

## Important
This is a catalog + cart + WhatsApp ordering website. It does not process online payments yet, and it does not automatically book courier pickups. Orders can be confirmed manually before dispatch through India Post or a private courier.
